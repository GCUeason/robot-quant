# Robot Quant

[![Daily prediction and simulation](https://github.com/GCUeason/robot-quant/actions/workflows/daily.yml/badge.svg)](https://github.com/GCUeason/robot-quant/actions/workflows/daily.yml)

针对机器人ETF易方达（`159530`）的公开、可复现量化实验。项目每天收盘后更新预测，并比较两个拥有相同现金流的模拟账户：

- **固定定投**：初始投入 ¥10,000，随后每月首个交易日投入 ¥1,000，并始终尽量满仓ETF。
- **预测策略**：使用相同现金流，根据滚动模型选择 0%、50% 或 100% 目标仓位。

## 模型方法

模型预测未来10个交易日机器人ETF易方达相对沪深300的超额收益方向。直接使用可交易ETF作为研究对象，避免指数行情与ETF实际成交之间的跟踪误差。特征仅使用预测时点已经存在的数据：

- 5、20、60日动量；
- 与20、60日均线的距离；
- 20日历史波动率和成交量比率；
- 相对沪深300的20日强弱；
- 沪深300相对120日均线的市场状态。

模型按月滚动训练带正则化的逻辑回归。训练集只包含标签结果已经发生的历史样本；样本不足时使用透明的趋势回退规则。当天收盘后生成的信号最早在下一交易日开盘执行，避免前视偏差。

## 模拟口径

- ETF：机器人ETF易方达 `159530`；
- 市场基准：沪深300 `000300`；
- 初始投入：¥10,000；
- 每月定投：¥1,000；
- 交易单位：100份；
- 默认佣金：成交额的0.03%，最低¥5；
- 默认滑点：单边0.05%；
- 行情来源：腾讯证券公开行情接口；
- 定时运行：工作日北京时间16:30，由GitHub Actions触发。GitHub定时任务可能排队延迟。

模拟从ETF可交易历史首日开始完整重算，因此对同一份行情重复运行不会重复定投。结果文件由定时任务自动提交回仓库。

预测策略首日先把¥10,000记入模拟账户；由于当时没有上一交易日信号，首日不强制满仓，之后才按模型给出的0%、50%或100%目标仓位交易。固定定投基线则从首日开始尽量满仓。

## 本地运行

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install ".[dev]"
python -m pytest
robot-quant run-daily
```

## 风险说明

这是研究和模拟工具，不连接券商，不会下真实订单，也不构成投资建议或收益承诺。公开行情可能存在延迟、复权或临时不可用等问题；实盘决策前必须使用持牌数据源和券商成交规则重新验证。
