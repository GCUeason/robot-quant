# Robot Quant

[![Daily prediction and simulation](https://github.com/GCUeason/robot-quant/actions/workflows/daily.yml/badge.svg)](https://github.com/GCUeason/robot-quant/actions/workflows/daily.yml)

针对机器人ETF易方达（`159530`）的公开、可复现量化实验。项目每天收盘后更新研究信号，并从2026年7月20日起跟踪既定现金流：

- **固定定投**：2026年7月20日首次买入 ¥15,000，随后从次月起每月首个交易日投入 ¥1,000，并始终尽量满仓ETF。
- **模型观察层**：保留滚动模型的0%、50%或100%原始研究仓位，但在逐日成熟样本质量门控完成并验证前，不允许模型改变可执行模拟仓位。

当前固定定投是唯一可执行模拟。“质量门控定投”与固定定投使用相同仓位，因此两者绩效应完全一致；这用于证明未验证模型确实没有暗中参与交易。

## 模型方法

模型预测未来10个交易日机器人ETF易方达相对沪深300的超额收益方向。直接使用可交易ETF作为研究对象，避免指数行情与ETF实际成交之间的跟踪误差。特征仅使用预测时点已经存在的数据：

- 5、20、60日动量；
- 与20、60日均线的距离；
- 20日历史波动率和成交量比率；
- 相对沪深300的20日强弱；
- 沪深300相对120日均线的市场状态。

模型按月滚动训练带正则化的逻辑回归。训练集只包含标签结果已经发生的历史样本；样本不足时使用透明的趋势回退规则。当天收盘后的研究信号与下一交易日执行计划分开显示，避免把10日标签误读为次日涨跌预测。

方案1已经启用：项目保留逻辑回归原始分数，同时使用 `CalibratedClassifierCV(method="sigmoid")` 校准概率；内部验证采用 `TimeSeriesSplit(gap=10)`，在训练与验证折之间隔离一个完整预测期。每月模型还只用当期训练集的1%至99%分位检查全部特征；任一特征越界时，日报明确列出分布外原因，保留原始研究概率但停用收益区间和卖出指标。

日报展示Brier分数、AUC、方向准确率，以及每隔10个交易日近似非重叠抽样后的Wilson 95%区间。目前还没有实现可安全回放的逐日成熟样本仓位门控，所以即使某次汇总验证看似通过，模型也不会自动获得交易权限。

## 收益与风险指标

日报对5、10和20个交易日分别给出：

- 历史相似状态的中位收益、10%～90%收益区间和¥15,000对应盈亏；
- 期末亏损概率、路径内下跌超过5%的概率，以及只在曾跌破现价路径中计算的低点日25%～75%窗口；
- 基于10日收益分布的风险控制价、止盈观察价与保持/观察/减仓/退出状态；
- 严格只使用当时已实现结果的滚动样本外MAE、零收益基线MAE、方向准确率和区间覆盖率；
- 每种卖出动作的历史触发次数、随后10日实际收益、亏损率和路径最差收益，并与全部可验证日期作描述性对照。

相似状态先要求沪深300趋势同号、20日相对强弱同号且差异不超过3个百分点，再按全部模型特征的标准化距离筛选。入选路径之间至少间隔对应的5、10或20个交易日，避免把连续日期的高度重叠结果重复计数。最多取40条，有效非重叠样本少于20条、完整状态距离不合格或当前处于训练分布外时，收益数字与卖出动作直接标记为不可用，不再回退混入不同市场状态。

## 模拟口径

- ETF：机器人ETF易方达 `159530`；
- 市场基准：沪深300 `000300`；
- 模拟开始日：2026年7月20日；
- 首次买入：¥15,000，按100%目标仓位执行；
- 后续定投：从次月起，每月首个交易日投入¥1,000；
- 交易单位：100份；
- 默认佣金：成交额的0.03%，最低¥5；
- 默认滑点：单边0.05%；
- 行情来源：腾讯证券公开行情接口；
- 定时运行：工作日北京时间16:30，由GitHub Actions触发。GitHub定时任务可能排队延迟。

2026年7月20日之前的行情仅用于训练模型，不计入账户收益。模拟账户从计划开始日完整重算，因此对同一份行情重复运行不会重复定投。首次建仓按用户设定的100%目标仓位执行，后续固定定投继续保持100%可执行目标仓位；模型给出的0%、50%或100%只记录为研究字段。结果文件由定时任务自动提交回仓库。

robot-quant run-daily

## 风险说明

这是研究和模拟工具，不连接券商，不会下真实订单，也不构成投资建议或收益承诺。公开行情可能存在延迟、复权或临时不可用等问题；实盘决策前必须使用持牌数据源和券商成交规则重新验证。
